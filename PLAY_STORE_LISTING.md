## English

Title: Fun Phone: Your private dialer

**Short description**

Private Android dialer with fast T9 search, favorites and local contacts

**Long description**

Make calls your way with a private Android dialer built around speed, clarity and control.

Find contacts with T9 search, call from favorites or recents, and manage incoming, outgoing and missed calls with clear controls. Fun Phone can replace your default phone app. Device Status helps you review permissions and the default dialer role.

Fun Phone processes contacts and call data on your device. Connected accounts may sync contacts under their own settings. The app has no ads, analytics, cloud account or developer-operated cloud. Contact photos are shared as local files through Android Sharesheet when you choose to share them.

Two optional features connect directly to the internet. Public holidays uses Nager.Date after your approval, requesting the selected country and year. Opening a website or social preview contacts the selected site, which receives the URL, IP address, cookies and technical request data under its own policy. Speech tools use your configured Android speech provider, whose processing may require a connection.

Personalize themes, colors, fonts, layouts and text size. Compact and large-text options help the app fit different screens, with labels and navigation designed for Android accessibility services and screen readers.

Calls and contacts come first. Enable only the extra tools you want: notes, checklists, reminders, expenses and budgets, QR utilities, voice tools, a local password vault with PIN or biometrics, Pomodoro, wellbeing, paint and games.

Highlights:
• T9 contact search
• Favorites, recents and missed calls
• Incoming and active-call controls
• Contact import, export and duplicate tools
• Themes, colors, fonts and adjustable text size
• Screen-reader-friendly labels and navigation
• Optional tools you can enable or hide
• Local password vault with PIN or biometrics
• No ads, analytics or developer-operated cloud

Android capabilities vary by device and version. After installation, open Device Status to complete permissions and choose Fun Phone as your default dialer.

## Preview assets — campaign v3

- Canonical source: `screenshots/store-v3/campaign.json` (stories, copy, per-capture style, theme
  and accent, composition theme). Real Compose UI captured on the Pixel 9 Pro emulator
  (1280×2856) with fictional names, notes, accounts and amounts, plus normalized fixture status
  chrome. Campaign v2 stays archived in `screenshots/store-v2/`.
- Phone masters: eight **1080×1920 RGB JPEGs** per locale in `screenshots/store-v3/{es,en,de,fr,pt}/`.
- Feature graphics: **1024×500 RGB JPEGs**, `feature-graphic.jpg` in each locale folder.
- Raw native captures: `screenshots/store-v3/raw/`. No real notifications, provider contacts or calls
  belong in these assets. The shell-only benchmark capture host uses its own fixture cache and
  refuses Contacts/Call Log permission; it must never preload or refresh the phone's provider.
  The incoming call is an in-memory fictional `UiCall`; no Telecom call is placed or received.
- Review sheets: `screenshots/store-v3/overview-{es,en,de,fr,pt}.jpg`.
- Backgrounds are deterministic CSS gradients declared per slide in `campaign.json`; there is no
  generated artwork in this campaign. App UI and all typography are rendered deterministically.
- Identical compositions feed the website's ES/EN WebP set.
- All five languages have localized headlines, subtitles, native UI and fictional sample content.
  Play locale mapping: `en-US`, `es-419`, `de-DE`, `fr-FR` and `pt-BR`; Portuguese copy follows the
  Brazilian wording used by the app.
- No ranking, awards, testimonials, price badges, installation CTA, hands or branded device hardware.
  Headlines fit inside the top 20% of each image. Specs follow
  [Google Play preview-asset guidance](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en).

Capture (isolated Community benchmark only; the script refuses non-emulator devices unless
`STORE_CAPTURE_ALLOW_PHYSICAL=1` is set):

```bash
./gradlew assembleCommunityBenchmark
adb -s <serial> install -r -t app/build/outputs/apk/community/benchmark/app-community-benchmark.apk
ANDROID_SERIAL=<serial> ./scripts/capture-store-previews.sh
# Or refresh only some languages:
ANDROID_SERIAL=<serial> ./scripts/capture-store-previews.sh de fr pt
```

The capture host accepts `scene`, `language`, `style` (`MODERN`, `MINIMAL`, `RETRO`), `dark`,
`darkStyle`, `accent` (a named app accent) and `number` extras; `campaign.json` lists every capture
and the taps needed to reach a state (country code, two-step code, yearly summary).

Export from the sibling `fun-phone-web` checkout with `npm run render:store`. This reads the
canonical capture set and emits both Play masters and website assets; it does not publish.
From another checkout or worktree pass the source: `npm run render:store -- /path/to/screenshots/store-v3`.
To export only some languages, add `--locales=de,fr,pt`.
The graphics are a review candidate. Release/Play predecessor gates still apply before uploading.

## Ready-to-paste listing text

`play-listing/` contains `title.txt`, `short-description.txt` and `full-description.txt` for all five
Play locales. The text is generated from the reviewed sections above; `play-listing/manifest.json`
maps each locale to its text directory, eight phone images and feature graphic.

```bash
python3 scripts/export-play-listing.py
./scripts/verify-play-listing.sh
```

The guard checks title/short/full limits, export freshness, native fixture coverage and the image
set for every language. Limits are 30, 80 and 4,000 characters respectively, per
[Google Play product-detail guidance](https://support.google.com/googleplay/android-developer/answer/9859152?hl=en).
The full descriptions consistently disclose optional social previews, holiday requests, Android
speech providers and account-managed contact synchronization. The 3.21.0 release notes above are ready for this local candidate; generating text does not upload it.

# Política de Marca / Trademark Policy

## Español

Este repositorio usa "**Fun Phone**" y su logotipo como identificadores del proyecto de Bookverse.
No contiene evidencia de un registro formal de marca; esta política no afirma que exista.

### Uso permitido
- Puedes usar el nombre "Fun Phone" para referirte al proyecto original (por ejemplo: "basado en Fun Phone" o "fork de Fun Phone").
- Puedes enlazar al repositorio oficial.

### Uso NO permitido
- **No puedes** distribuir una versión modificada usando el nombre "Fun Phone" ni el logotipo oficial sin autorización escrita de Bookverse.
- **No puedes** usar el nombre "Fun Phone" de manera que sugiera que tu versión es la oficial o está respaldada por Bookverse.
- **No puedes** registrar dominios, cuentas de redes sociales o listings de tiendas de aplicaciones usando "Fun Phone" para distribuir versiones no oficiales.

### Si haces un fork
Si distribuyes una versión modificada de esta app, **debes**:
1. Cambiar el nombre de la aplicación.
2. Cambiar el logotipo e iconos de la app.
3. Cambiar el `applicationId` en `build.gradle.kts`.
4. Indicar claramente que tu versión es un fork independiente.
5. Cumplir con los términos de la licencia GPL v3.

### Assets gráficos protegidos
Los siguientes assets están protegidos por derechos de autor y **no están cubiertos** por la licencia GPL v3 del código:
- Iconos de la aplicación (`mipmap-*/ic_launcher*`)
- Avatares personalizados (`drawable/avatar_*`)
- Imagen "about" (`drawable/about.webp`)
- Screenshots promocionales (`new_images/`)

Estos assets son propiedad de Bookverse y no pueden ser redistribuidos en forks sin autorización.

## English

This repository uses "**Fun Phone**" and its logo as identifiers of the Bookverse project. It does
not contain evidence of a formal trademark registration, and this policy does not claim one exists.

### Permitted use
- You may use the name "Fun Phone" to refer to the original project (e.g., "based on Fun Phone" or "fork of Fun Phone").
- You may link to the official repository.

### NOT permitted
- You **may not** distribute a modified version using the "Fun Phone" name or official logo without written authorization from Bookverse.
- You **may not** use the "Fun Phone" name in a way that suggests your version is official or endorsed by Bookverse.
- You **may not** register domains, social media accounts, or app store listings using "Fun Phone" to distribute unofficial versions.

### If you fork
If you distribute a modified version of this app, you **must**:
1. Change the application name.
2. Change the logo and app icons.
3. Change the `applicationId` in `build.gradle.kts`.
4. Clearly indicate that your version is an independent fork.
5. Comply with the GPL v3 license terms.

### Protected graphic assets
The following assets are copyrighted and are **not covered** by the GPL v3 code license:
- Application icons (`mipmap-*/ic_launcher*`)
- Custom avatars (`drawable/avatar_*`)
- About image (`drawable/about.webp`)
- Promotional screenshots (`new_images/`)

These assets are property of Bookverse and may not be redistributed in forks without authorization.

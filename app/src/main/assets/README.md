# Assets Folder

## match_sound.ogg
Este es un archivo de sonido placeholder para el juego de Cartas de Memoria.

**Para reemplazarlo con un sonido real:**
1. Crea un sonido corto (0.2-0.5 segundos) de "match exitoso"
2. Exportalo como OGG Vorbis
3. Reemplaza este archivo manteniendo el nombre `match_sound.ogg`

**Herramientas sugeridas:**
- Audacity (exportar como OGG Vorbis)
- Freesound.org (sonidos gratuitos)
- LMMS o cualquier DAW
